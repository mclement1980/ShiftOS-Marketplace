# DISPATCH Output Examples

These fictional Riverbend artifacts calibrate the three outputs from a complete DISPATCH run. Riverbend is a classroom-safe lodging-partner example with no real partner data.

## Files

- `example-dispatch-brief.md` — the complete eight-step record and build-approval contract.
- `example-draft-artifact.md` — a real first version with visible `[PLACEHOLDER]`, `[REPLACE:]`, and `[TBD]` gaps.
- `example-dispatch-debrief.md` — a compact reflection and evidence-level close.

## Emulate

- A concrete filename and finished-state sentence
- Project-specific Interview findings
- Have / Missing / Unsure with a route out of every gap
- One approved Plan that ends in a stop
- Three real Alternatives, a selection, and a reason
- Absolute Tripwires
- A four-sentence Continue paragraph
- A Handoff with destination, people, tests, permissions, and return evidence
- Grep-able placeholders
- Honest evidence states

## Do not emulate

- Riverbend’s fictional facts or artifact shape
- Any implied external-sharing authority
- Markdown when the named deliverable requires another format
