# Role Master Prompt — Structure Template

This is the canonical structure for `ME/role-master-prompt.md`, the file the Role OS Interview produces. Match the headings, tables, and level of specificity exactly. Every section is filled from the participant's interview answers — no invented content, no padding. If a section has nothing real in it, keep the heading and write one honest line rather than fabricating.

---

---

## Notes for the interviewer

- **Version line:** on update visits, bump the version (1.0 → 1.1) and refresh the date. Keep "Built by me via the Role OS Interview."
- **Tables stay tables.** They're scannable for both the participant and the agents that read this file every session.
- **The two short lists under "What I own"** (undocumented work, assigned-but-not-done) are where the real role lives. Never drop them, even if short.
- **The quality bar:** this file should make a brand-new colleague dangerous in a week.
