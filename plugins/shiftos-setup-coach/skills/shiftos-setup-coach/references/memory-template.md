# Memory File — Template and First-Entry Guidance

`ME/memory.md` ships with the workspace, so the Setup Coach normally only appends the first entry (Step 8) and the completion entry (Step 11). If the file is ever missing or damaged, recreate it with this structure.

---

## The template

```markdown
# Memory — Universal

What agents learn about the owner that stays true across all work: preferences, standing context, corrections worth keeping. Project-specific memory lives in each project's own `memory.md`, not here.

**Format:** `- YYYY-MM-DD — [the fact, one or two lines]` · newest first · write it the moment you learn it.
**Rotation:** past ~150 lines, merge the oldest entries into the "Established context" block below and remove the originals.

## Established context

*(Empty until the log earns its first compression.)*

## Log
```

---

## What earns an entry

- A correction the owner made that should never need making twice ("the board chair goes by R., never Robert").
- A stated preference not already in another ME/ file ("internal drafts can use estimated figures if labeled").
- A decision about how owner and system work together ("triage the Inbox on Fridays").
- Standing context that would be expensive to rediscover ("the co-op program renews in October — partner conversations get sensitive from August").
- A pointer for a future session ("rich convention-sales material in setup — flag for Session 5").

## What doesn't

- Anything already captured in another ME/ file — no duplicates; the files stay the source of truth.
- Progress, blockers, or decisions tied to one project — that project's own `memory.md` is where they belong.
- Session trivia that won't matter in two weeks.

## The first entry (written in Step 8, together)

Shape, not script — draft it from the day's conversation and let the owner adjust:

```
- [YYYY-MM-DD] — Setup complete. [Name], [role] at [organization]. [One or two of the sharpest preferences from setup.] [Anything flagged for later sessions.]
```

A good first entry is concrete enough that a session reading only this line would already behave noticeably better. "Prefers bullets, works at a DMO" fails that bar. "Bottom line first even when the news is bad; STR report outranks the dashboard when numbers conflict" clears it.
