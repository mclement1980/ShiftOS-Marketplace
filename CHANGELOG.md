# Changelog

All notable public changes to the ShiftOS Marketplace are recorded here.

## 1.0.0 — 2026-07-27

- Introduced ShiftOS-DISPATCH for Claude and Codex.
- Established Codex as the reference/default route and Claude as a fully supported route under the same semantic and proof contract.
- Added repository-marketplace installation and direct-skill ZIP fallback assets for both routes.
- Added deterministic manifest, archive, payload-parity, safety, and public-content validation.
- Preserved the pre-v2 Marketplace at the immutable `legacy-marketplace-v1` tag.
