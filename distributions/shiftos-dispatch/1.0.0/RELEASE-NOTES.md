# ShiftOS-DISPATCH 1.0.0

ShiftOS-DISPATCH is available in synchronized Claude and Codex packages. Every cohort receives both packages; each participant chooses the single package for the platform they already use.

Codex is the ShiftOS reference/default implementation. Claude is fully supported under the same semantic workflow and proof contract.

Invoke either route by saying:

> Run DISPATCH.

The repository Marketplace routes use platform-native plugin wrappers. The downloadable ZIP fallbacks are direct-skill packages: extract the `dispatch` folder and follow the route-specific runtime guide inside it.

This release provides guided preparation, approval, production, verification, and handoff for one real deliverable. Installation alone is not exercise completion and does not establish transfer into workplace practice.

Package integrity is recorded in `SHA256SUMS`.
